
# Tailwind Newsletter UI

A simple and responsive Newsletter Subscription UI built using HTML and Tailwind CSS.

## 🚀 Technologies

- HTML5
- Tailwind CSS
- Vite

## ✨ Features

- Responsive design
- Gradient header
- Newsletter subscription form
- Tailwind CSS utility classes
- Clean and simple UI



## 🛠️ Run Locally

```bash
npm install
npm run dev
